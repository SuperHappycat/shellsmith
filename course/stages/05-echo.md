title: Say it back with `echo`
chapter: Basics
difficulty: easy
---

`echo` prints its arguments separated by single spaces, followed by a newline.

```
$ echo lotus river
lotus river
$ echo   lotus      river
lotus river
$ echo

```

Arguments are separated by **any run of whitespace**, so extra spaces between words disappear. `echo` with no arguments prints an empty line.
